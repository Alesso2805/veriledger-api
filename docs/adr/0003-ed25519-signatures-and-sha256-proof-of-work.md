# ADR-0003: Ed25519 signatures and SHA-256 Proof of Work

- **Status:** Accepted (retroactive)
- **Date:** 2026-07-29, written down on 2026-10-20
- **Related:** SPEC.md › Signing and hashing contract; ADR-0004; commits `6cbca3d`, `9bb1c8f`

## Context

A transaction must prove who authored it, and a block must be costly to forge so that a peer cannot rewrite history for free. The webapp signs in the browser, so the scheme needs a well-reviewed JavaScript implementation as well as a Python one.

## Options

- **Signatures:** ECDSA secp256k1 (Bitcoin's), or Ed25519. Ed25519 is deterministic (no nonce to get wrong), has small fixed-size keys and signatures, and has audited libraries on both sides: `cryptography` in Python and `@noble/curves` in the browser.
- **Consensus:** Proof of Work, Proof of Stake, or a fixed set of validators. Proof of Work is the one a reader recognizes and can check with a hash function alone.

## Decision

- **Ed25519** with raw keys in lowercase hex: the 32-byte public key is the address; signatures are 64 bytes. The API only verifies (`Ed25519ServiceImpl.verify_signature`); keys are generated by their owner.
- **SHA-256 Proof of Work** over a sorted-key JSON of the block, with a difficulty of 4 leading hex zeros (about 65,000 hashes on average, well under a second).
- **Reward:** a coinbase transaction from `SYSTEM`, signature `COINBASE`, of 50 plus the block's fees.
- **Consensus:** the longest valid chain among registered peers.

## Consequences

- The server-side `POST /wallets/generate` contradicts "keys are generated by their owner"; it stays for development only (VLA-21) and the webapp generates keys itself (VLW-16).
- Difficulty and reward are constants in `MineBlockUseCase`; VLA-17 moves them to settings. There is no difficulty adjustment, by scope.
- "Longest valid chain" is only as strong as the validation; today it checks the hash links only, so VLA-18 implements the full rules of SPEC › Valid chain.
- What is signed and how it is serialized was left implicit and broke between Python and JavaScript; ADR-0004 fixes it.
